# Thống nhất nội dung giao diện — mục 9

- Khám phá: mô tả đúng chức năng, bỏ lời quảng bá hàng trăm khóa; bỏ thống kê giảng viên không có dữ liệu; bỏ nhãn Mới dựa trên vị trí.
- Số tài liệu dùng nhãn tài liệu thay vì PDF vì API đếm nhiều định dạng. Thẻ, chi tiết và Dashboard thống nhất cách gọi.
- Trình độ chưa có dữ liệu hiển thị Chưa cập nhật trình độ, không tự coi là Cơ bản.
- Tìm kiếm có nhãn truy cập rõ ràng; bỏ nút tìm kiếm không có hành động (danh sách lọc trực tiếp khi nhập).
- Khóa học của tôi: thay Cập nhật gần đây (không có ngày đối chiếu) bằng Khóa đã đăng ký.
- Gợi ý theo bài thống nhất Nên ôn tập / Chưa đủ dữ liệu / Đạt ngưỡng. Bộ lọc, thống kê, bảng chi tiết cùng nhãn.
- Nhóm chương dùng bài được gợi ý, không gọi toàn bộ bài ít dữ liệu là bài cần ôn; mục chương ít dữ liệu không hiện phần trăm.
- Không đổi điểm, ngưỡng, dữ liệu bằng chứng, ghi danh hoặc thanh toán.

Kiểm tra: 23 kiểm thử dữ liệu frontend; 24 kiểm tra UI Khám phá và 22 kiểm tra UI sau quiz bằng API giả lập đều đạt; build thành công. Còn cảnh báo CSS font import và bundle lớn đã có trước.
